TSUM ID Extractor — проект для Vercel

В архиве:
- index.html — интерфейс сервиса
- api/extract.js — серверная функция, которая загружает страницу tsum.ru и извлекает item_id
- vercel.json — конфигурация Vercel

Как опубликовать бесплатно:
1. Создайте новый публичный или приватный репозиторий на GitHub.
2. Распакуйте архив и загрузите в корень репозитория файлы index.html, vercel.json, package.json и папку api.
3. Войдите на https://vercel.com через GitHub.
4. Нажмите Add New → Project и импортируйте репозиторий.
5. Для обычного проекта оставьте настройки по умолчанию и нажмите Deploy.
6. После публикации откройте выданный адрес *.vercel.app.

Важно:
- Это не один автономный HTML-файл: браузер не может надёжно загружать tsum.ru напрямую из-за CORS. Поэтому проект включает маленькую Vercel Serverless Function.
- Проект не требует платных API и внешней базы данных.
- Бесплатный тариф Vercel имеет лимиты на серверные функции; при обычном личном использовании они, как правило, несущественны, но зависят от действующих условий тарифа.
- TSUM может менять HTML, включать антибот-защиту или ограничивать запросы с IP-адресов дата-центров. В таком случае функция вернёт ошибку; потребуется другой способ загрузки страницы.
- Серверная функция принимает только HTTPS-адреса домена tsum.ru и его поддоменов.
